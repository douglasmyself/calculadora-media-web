# 🎓 Calculadora de Média Escolar Web

Aplicação web simples e intuitiva desenvolvida para auxiliar estudantes e professores no cálculo rápido de médias escolares.

## 🚀 Funcionalidades
- Entrada de notas com validação de campos.
- Cálculo automático de média aritmética.
- Feedback visual imediato com o status do aluno (Aprovado / Recuperação).

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura da página.
- **CSS3:** Estilização responsiva e moderna.
- **JavaScript (ES6):** Manipulação de DOM e lógica de cálculo.
